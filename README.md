
# Student Grade Manager

基于 Java 21 和 MVC 架构的学生成绩管理系统。

## 技术栈
- Java SE 21
- MVC
- Collections / Lambda / Stream
- CSV 文件存储
- Git / GitHub

## 主要功能
1. 学生信息增删改查
2. 成绩统计和排序
3. 班级成绩分析
4. CSV 数据持久化
5. 成绩报告导出

## 项目特性
- 中间会介绍一些Java引入的新的特性和方法，所以只有c++基础也可以直接使用这个项目来学习Java SE
